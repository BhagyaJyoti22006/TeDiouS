1. Open `q-mcp-server-live-server/index.py` and replace `<roll>` with the correct roll number and `<ALLOWED_CORS_ORIGIN>` with the assigned values.

2. Open terminal in the directory `q-mcp-server-live-server`.

3. Run following command:  
`vercel --prod`

4. Follow the instructions to publish the project. Choose a name like `<roll>-q-mcp-server-live-server`. 

5. Copy the `Aliased` URL which would be like `https://<roll>-q-mcp-server-live-server.vercel.app/mcp`.
